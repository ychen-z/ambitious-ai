# ambitious-ai（野心任务重构）

[English](README.md) | **简体中文**

一个 Claude skill：在执行你的任务之前，先把它重构成一个更有野心的版本。

大多数人用 AI 执行的是自己猜到的第一个方案——"修这个 bug"、"填这个模板"、"画个图表"。这个 skill 会把任务往上推到它真正服务的目标。方法论提炼自一位 Anthropic 工程师的教程：你用 AI 的方式，可以更有野心。

## 三个杠杆

| 杠杆 | 做什么 | 例子 |
|---|---|---|
| **拉高视角** | 沿目标阶梯向上爬，而不是执行字面请求 | "修这个崩溃" → "让应用不崩溃" |
| **往深了挖** | 用领域顶尖专家真正在用的工具和方法干活，而不是专家腔的说法 | 流失分析：建统计模型，而不是画个表格 |
| **跨界组队** | 把任务从名词改写成动词，然后组建多领域工作角色（含对立角色） | "一份季度 PPT" → "让忙碌的人相信一个因果故事，并在不确定下做出决策" |

两条护栏：
- **前置条件**：有野心的活儿卡在工具和数据访问上，不在措辞上——先把这些配好。
- **外部验证**：永远别让 AI 给自己的作业打分。

## 具体案例使用说明

以下四个案例展示了 skill 的完整工作方式：你说什么 → skill 给出什么 → 你选哪一档 → 得到什么。更多领域模板（学习/读书、个人决策、code review、系统设计、写作、会议纪要）见 [references/scenarios.md](references/scenarios.md)。

### 案例 1：季度汇报 PPT（拉高视角）

**你说：**
> 帮我把这个季度的数据填进汇报 PPT 模板

**skill 触发后，先不干活，而是给你一串阶梯：**

| 档位 | 交付物 |
|---|---|
| L0 照做 | 填好的模板 |
| L1 上探 | 基于全量数据分析：这个季度什么变了、为什么变、接下来做什么 |
| L2 决策 | 当前最紧迫的 3 个决策，每个附正反论点，可以直接带上会讨论 |
| L3 重设计 | 质疑汇报形式本身——设计一套更好的机制，用历史数据证明它能更早发现问题，跑一个季度验证 |

**你选 L2，得到：** 一份决策备忘录，而不是 40 页没人看的片子。会议从"我讲你听"变成"直接辩论"。

> 判断口诀：如果这件事做完之后还要开会讨论，就可以试试把视角拉高。

### 案例 2：修崩溃 Bug（拉高视角 + 前置条件）

**你说：**
> 帮我修这个空指针崩溃

**skill 给出的阶梯：**

| 档位 | 交付物 |
|---|---|
| L0 | 修复这一处崩溃 |
| L1 | 排查并修复这一类崩溃（同模式的其他代码点） |
| L2 | 目标改为"让应用不崩溃"——持续监控、自主定位、验证修复 |

**选 L2 时，skill 会先检查前置条件，而不是硬干：**
- 能自主查看崩溃报告？
- 能查到每个版本对应哪段代码？
- 有一台能复现问题、验证修复的环境？

缺哪个，第一步就是把哪个配好。这就是"野心卡在工具上，不在措辞上"。

### 案例 3：用户流失分析（往深了挖）

**你说：**
> 分析一下我们的用户流失，画个图表

**skill 不会只画个表，而是按专家工作流推进：**

1. **换真方法**：像数据科学家那样在数据库里建统计模型，而不是用表格凑数
2. **定荒谬目标**：不满足"描述流失"，把"最早预测流失信号"的时间点往前推到极限——不合理的目标逼出非常规方法
3. **检验信念**：把原始数据直接给它（不告诉结论），验证"流失是新手引导问题"这个假设到底站不站得住
4. **找盲点**：用历史数据建用户行为模拟，找出你们还没注意到的最早流失信号
5. **外部验证**：用留出数据集检验模型效果——不让 AI 自己给自己打分

### 案例 4：产品发布文案（跨界组队）

**你说：**
> 帮我们的新产品写一篇发布文案

**第一步，skill 把名词换成动词：**

> 不是"一篇文案"，而是"让一群刷手机的人在 3 秒内停下来，30 秒内相信这个产品能解决他们的具体问题"。

动词一换，能借力的领域立刻清晰，然后组队干活：

| 角色 | 实际工作 |
|---|---|
| 记者 | 找出故事的主线和钩子 |
| 编辑 | 把关质量、删掉废话 |
| 做空研究员 | 从反面攻击：这个产品会被什么理由拒绝？ |
| 目标用户代理 | 用真实场景压力测试文案 |

**关键区别**：不是让 AI 用做空研究员的*口吻*写东西，而是让它*做空研究员实际会做的研究*。角色扮演和真干活是两回事。

### 反例：不触发的时候

> 法国的首都是哪里？
> 帮我把这封邮件语气改温和一点

这类查事实、改一行字的快速任务，skill 会直接闭嘴照做。**野心是有成本的**，只用在值得的任务上。

- **自动**：给出一个"是更大目标的症状"的任务，如上面 4 个案例的输入
- **手动**：`用 ambitious-ai 帮我重构这个任务：<你的任务>`
- **只要提示词**：直接查看 [references/prompts.md](references/prompts.md)
- **要你所在领域的阶梯模板**：查看 [references/scenarios.md](references/scenarios.md)——学习、决策、code review、系统设计、写作、会议六大场景
